## Twitter/X banner

Generate a ready-to-upload 1500×500 banner using the same follower data:

```sh
github-community-wall followers YOUR_USERNAME \
  --twitter-banner \
  --output assets/followers-banner.png
```

The banner is only the square avatar wall rearranged into a 1500×500 layout;
there is no title, template, text, or decorative overlay.
