# Code of Conduct

## Our standard

We expect everyone participating in this project to be respectful, constructive,
and inclusive. Harassment, discrimination, personal attacks, and deliberately
disruptive behavior are not acceptable.

## Maintainer response

Project maintainers will remove or edit unacceptable content and may temporarily
or permanently restrict participation when needed to protect the community.

## Reporting

Report conduct concerns privately to a maintainer through the contact details
on the repository owner's GitHub profile. Please include links or context and
avoid sharing more personal information than necessary.
